# 🧮 Vue 3 Scientific Calculator

A powerful, modern, and modular scientific calculator built with Vue 3 and Tailwind CSS. Supports basic arithmetic, scientific functions, memory operations, keyboard input, and persistent history.

---

## 🚀 Features

- ✅ Basic arithmetic: `+`, `−`, `×`, `÷`, `%`, `^`
- 🧪 Scientific functions: `√`, `∛`, `x²`, `x³`, `sin`, `cos`, `tan`, `log`, `log10`, `abs`, `1/x`, `π`
- 💾 Memory operations: `M+`, `M-`, `MR`, `MC`
- 📜 History log (auto-saves using localStorage)
- ⌨️ Full keyboard support
- 🔙 Backspace + Reset
- 🚫 Error handling: handles division by zero and invalid input gracefully
- 🎨 Styled with Tailwind CSS
- 🔧 Modular component structure using `<script setup>`


---

## 🛠️ Tech Stack

- [Vue 3 + Composition API](https://vuejs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Math.js](https://mathjs.org/)
- [LocalStorage](https://developer.mozilla.org/docs/Web/API/Window/localStorage)
